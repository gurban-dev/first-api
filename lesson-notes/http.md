# Web Development & Database Fundamentals

### GET Request
A GET request is an HTTP method used to retrieve data from a server.

* **Example:** Every time you type `google.com` into your browser's address bar and press Enter, the client sends an HTTP GET request to the server to load Google's homepage.

---

### POST Request
A POST request is an HTTP method used to send data to a server and usually creates a new resource.

* **Example:** A row is added to a database table to keep track of a new book.

---

### SQLite3
SQLite3 is a relational database management system that implements an SQL database engine. This is a module in Python that makes it possible to connect to a local database file.
