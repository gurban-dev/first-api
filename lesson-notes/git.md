Git is a version control system. It is designed to track changes in source code during software development. A version system system tracks changes made in a filesystem overtime. It allows a previous version of the code to be cloned in case a newer version breaks it.

GitHub is a cloud-based hosting service built on top of Git where developers store their projects.

git clone downloads an existing repository from GitHub. It creates the project folder, downloads all of the project's files and initialises Git inside the folder for you.
git clone <https_link_for_github_repo>

E.g.
git clone https://github.com/gurban-dev/first-api.git

A repository is project directory managed by a version control system.
